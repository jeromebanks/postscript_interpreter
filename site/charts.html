Charts — paper-ready data visualization

Interactive demos of lib/graph.ps (function and surface plotting) and lib/dataviz.ps (bar / line / area / scatter / pie). Pick a preset, edit the data or function, press Run. The PostScript source below is complete and self-contained — no (lib/...) run needed in the browser; copy it verbatim into a file with (lib/graph.ps) run / (lib/dataviz.ps) run for paper use. See .claude/skills/psviz for the agent-authoring guide.

Presets are plain, white-background figures suitable for papers. Edit the array [ ... ] or the { ... } proc and re-run. For local files, add (lib/graph.ps) run or (lib/dataviz.ps) run at the top and render with pscat --png out.png file.ps.
