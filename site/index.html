A PostScript interpreter, written in Rust,
for watching programs draw.

Not a Ghostscript replacement — a from-scratch Level 2 interpreter built to relive sending hand-written PostScript straight to a LaserWriter, and to watch the recursion happen, live.

live winit window PNG · SVG · PDF out runs in the browser (wasm) Type 1 · Type 3 · TrueType text save/restore VM filters & sampled images MCP server + agent skill golden-tested against Ghostscript

Try it now

The playground runs the full interpreter in your browser tab — type PostScript, watch it draw, no install. Or build the real thing:

git clone https://github.com/jeromebanks/postscript_interpreter
cd postscript_interpreter
cargo run --release -- --page 500x500 examples/sierpinski.ps   # watch it draw
cargo run --release -- --png out.png file.ps                   # headless render
cargo run --release -- -i                                      # REPL + live window

What's inside

  • The language core — tokenizer, object model, a three-stack machine with an explicit frame stack (no recursion), catchable errors with the standard PostScript names, tail-call-safe loops, save/restore as copy-on-write journaling.
  • Graphics — paths, fills, strokes, clipping chains, dash patterns, HSB/CMYK/Indexed/Separation color, sampled images with decode filters (ASCIIHex/85, RunLength, Flate, LZW, DCT/JPEG), halftone screening, multi-page documents.
  • Text — the standard base fonts (metric-compatible Liberation faces), Type 3 glyph programs, and real Type 1 fonts: currentfile eexec, encrypted charstrings and all.
  • Output — a live window (arrow keys browse pages), PNG at any dpi, SVG and PDF export verified by letting Ghostscript rasterize them back, a spool mode that watches a directory like the printer in the corner of the lab.
  • A font library — original Type 3 display faces where every glyph is a program: neon tube, marquee bulbs, star charts, chiseled stone, and a dynamic handwriting font where no two letters ever match. See the gallery.

Why

I used to write raw PostScript by hand in college and send it straight to a LaserWriter. This is a from-scratch Rust interpreter built to relive that — watching a hand-written recursive PostScript program draw itself, live, without depending on a decades-old C codebase to do it.

pscat — built by hand, tested against Ghostscript, drawn live.
