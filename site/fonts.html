Fonts

Every face findfont can reach, rendered by pscat itself. Two families: eight Type3 faces whose glyphs are PostScript programs (lib/fonts/), and a 62-file runtime catalog (fonts/catalog/) of libre outline faces loaded from disk on first use — together they resolve every classic LaserWriter 35 name, plus 35 more display and text families and four international-script faces (Korean, Japanese, Thai). Run pscat --fonts for the complete, current list of names and aliases.

The Type3 library

Original display faces where every glyph is a program, so the letterforms do things outline fonts can't — see Architecture for how Type3 glyph procedures feed the same transform pipeline as everything else. Self-contained files, draw nothing on load, run unchanged in Ghostscript.

The standard thirty-five

Every classic LaserWriter name resolves to a metric-compatible libre face: the bundled Liberation faces cover Helvetica/Times/ Courier, TeX Gyre covers Palatino, Bookman, New Century Schoolbook, Avant Garde, and Zapf Chancery, and the URW symbol faces give /Symbol and /ZapfDingbats real glyphs with their proper PLRM encodings.

Bold, italic, and bold-italic cuts ride along for every text family.

The display shelf

35 curated families from the Google Fonts collection (all OFL or Apache 2.0) spanning garalde to arcade, script to blackletter. Drop your own .ttf/.otf into any fonts/catalog/ subdirectory and /<FileStem> findfont finds it — the manifest has the full family/license table.

International scripts

Hangul, kana/kanji, and Thai vastly exceed the 256-slot Encoding array every other face above uses, so these four are "Unicode-mode" instead: show decodes the string as UTF-8 and maps codepoints straight to glyphs via the font's own cmap, skipping Encoding/glyph-name resolution entirely — see Architecture and FONTS.md's "Unicode-mode catalog faces" addendum for the mechanism and its limits (no GPOS/mark shaping yet).
