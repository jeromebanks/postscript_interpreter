Gallery

Everything below is pure PostScript, rendered by pscat itself. The generative pieces are deterministic — change a /seed and a different tree grows. Many run live in the playground.

Generative art

Written for this interpreter, each piece within the operator set it had at the time — the Stage 3 originals predate rand and arrays, so they carry their own LCG and HSB converter as PostScript procedures.

The font library

Original Type 3 display faces (lib/fonts/) — every glyph is a program, so the letterforms do things outlines can't. Self-contained files; each runs unchanged in Ghostscript.

The specimen poster/Neon (glow by overdraw), /Marquee (bulbs, glints, burnouts), /Constellation (star charts), /Lapidary (chiseled stone)
The second folio/Circuitry (copper traces, pads, and vias), /Stitchwork (cross-stitch on the 45° grid), /Confetti (a thrown handful, still falling)
/HandScriptDynamic handwriting — rand-jittered strokes, wandering baseline, varying pen pressure; no two letters ever match

The font catalog

Beyond the Type 3 library, fonts/catalog/ holds 58 libre outline faces loaded at findfont time — the complete LaserWriter 35 resolved to metric-compatible faces (TeX Gyre, URW symbols) plus a display shelf from garalde to arcade. pscat --fonts lists every name.

The Standard Thirty-FiveEvery classic name — Palatino, Bookman, Avant Garde, Zapf Chancery, Symbol, Dingbats — resolved libre
The CatalogA face for every occasion: 35 families across serif, sans, slab, script, blackletter, western, horror, pixel, sci-fi…
